# Логика по Челпанову — курс и тренажёр

Сайт для изучения логики по «Учебнику логики» Г. И. Челпанова: 26 уроков, 14 тренажёров, «Софизм дня»,
тренажёр «Софизм или нет?», каталог уловок, справочник и карточки мыслителей (Аристотель, Бэкон, Милль и др.).

Работает без сервера и без интернета: обычная статическая страница (HTML, CSS, JavaScript без библиотек).
Прогресс хранится в браузере (localStorage), его можно скачать и загрузить на странице «Прогресс».

## Как открыть

- **Локально:** откройте `index.html` двойным щелчком (лучше в Chrome или Edge).
- **Если PDF учебника лежит рядом** (`chelpanov_logika.pdf` в одной папке с `index.html`), ссылки «Читать в учебнике» открывают нужную страницу.
  В публичной версии PDF не выложен.

## Структура

- `index.html` — оболочка страницы;
- `app/js` — движок: маршрутизация, тренажёры, виджеты, страницы;
- `app/data` — уроки, каталог уловок, база рассуждений, глоссарий, мыслители;
- `app/data/daily-extra.js` — сюда добавляются новые рассуждения для «Софизма дня».

## Источники и оговорки

Конспекты написаны заново; примеры и порядок глав — по учебнику Челпанова (издание 1915 г.).
В исходном PDF глава XXVI оборвана, поэтому ошибки индукции и различие софизма и паралогизма дописаны
составителем и помечены как «дополнение». Сведения в разделе «Мыслители логики» собраны из открытых источников
(Stanford Encyclopedia of Philosophy, Википедия) и пересказаны своими словами; ссылки — в карточках.
